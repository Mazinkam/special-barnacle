# Publishing this skill as a private repo

The skill is now a git repo with a single initial commit on `main`.
No remote is configured yet — that's intentional. Add your own
private remote and push when ready.

## 1. Create the empty private repo on your host

### GitHub

```bash
# Create the repo on github.com first (web UI or `gh repo create --private`),
# then add the remote locally:
REPO=/Users/abdulkarim/.local/share/agent-skills/hierarchical-agent-orchestrator
cd "$REPO"
git remote add origin git@github.com:<your-github-id>/hierarchical-agent-orchestrator.git
git push -u origin main
```

Replace `<your-github-id>` with your GitHub username (likely `abdulkarim`).

### GitLab

```bash
REPO=/Users/abdulkarim/.local/share/agent-skills/hierarchical-agent-orchestrator
cd "$REPO"
git remote add origin git@gitlab.humain.com:<your-gitlab-path>/hierarchical-agent-orchestrator.git
git push -u origin main
```

## 2. Verify the push

```bash
cd "$REPO"
git remote -v
git log --oneline -1
```

| `tests/` | Python tests for the reference runtime |

## Excluded from the repo (already in `.gitignore`)

| Path | Why |
|---|---|
| `.orchestrator/` | Local runtime state — different on every machine |
| `__pycache__/`, `*.pyc`, `.pytest_cache/` | Generated bytecode |
| `.orchestrator/*.jsonl` | Append-only event streams (durable history lives in `~/.local/state/coding-agent-orchestrator/`) |
| `.orchestrator/ledger.json`, `dashboard.html` | Rebuildable materialized views |

The runtime state for any machine using this skill belongs in the
shared canonical state root `~/.local/state/coding-agent-orchestrator/`,
not inside the skill directory. The skill ships the *code*, the
machine produces the *events*.

## Pre-publish verification

Before pushing, run the three verification gates from a clean tree:

```bash
python3 -m pytest -q
bash scripts/typecheck-bridge.sh
bash scripts/lint.sh
```

`scripts/lint.sh` runs `ruff check`, `vulture` (dead-code, Python) and `knip --production`
(unused exports, bridge TS) and exits non-zero on any finding or tool failure.
